# Orren — Canonical Architectural Specification v1.0

This repository companion records the supplied canonical architecture.

## Identity

Orren is the intelligence of language, meaning, context, and expression. It is a semantic intelligence and realization engine that preserves meaning while allowing realization across languages, platforms, runtimes, and modalities.

**Core proposition:** meaning is primary; implementation is secondary.

## Principles

1. Meaning is primary; implementation is secondary.
2. Truth lives in the SIR graph alone.
3. No modality is canonical.
4. Meaning survives transformation; degradation is explicit.
5. Equilibrium replaces unilateral authority.
6. Conflicts are non-destructive and produce resolution nodes.
7. Agents never block one another.
8. Partial realization is allowed.
9. Provenance is mandatory.
10. Scope is bounded by the active vertical slice.

## Semantic model

Every SIR node carries expression, cognitive, vibe, spatial, temporal, relational, conditional, behavioral, and equilibrium dimensions. Equilibrium is cross-cutting: it mediates the other dimensions and governs field-level balance.

## Living field

The SIR field is one shared graph and the only communication medium between agents. Agents read from it and write to it; they never call one another directly.

## Agent classes

Producers inject partial intent. Refiners enrich without overwriting. Resolvers detect conflicts and emit proposals. Realizers emit artifacts from resolved-enough views. Observers record provenance, persistence, validation, determinism, dialogue, and degradation metadata.

## First proof

The first milestone is the Living SIR Field: inject intent, refine it, resolve conflict, realize partial artifacts, preserve provenance, and demonstrate non-blocking agents.
